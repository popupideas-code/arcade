Your goal

The four orbs below are pushed around by one secret law. The law never changes, so you can find it by testing, like a scientist. Figure out the law, then prove it by predicting where the orbs end up.

Score: 40 for naming the law, 5 for each correct prediction, 3 for each experiment you did not need.

  1. 1ExperimentSet up the orbs, press Run, and watch what the law does. You get 6 runs.
  2. 2PredictTwo tests. Place a pin where you think each orb will end up.
  3. 3Name the lawPick the rule that explains everything you saw.

  • Orb. The number is its ID.
  • →Arrow: the direction and speed it starts with.
  • Pin: your prediction for that orb.
Each pin matches the orb with the same number.

Stuck? Ideas to test
  • Does color matter? Put orbs 1 and 3 (both red) close together, away from the others. Run. Then do the same with 1 and 2 (red and blue).
  • Does speed matter? Press Remove arrows so every orb starts at rest, and run. Then run again with long arrows.
  • Do the walls matter? Put one orb near a wall with no arrow and see where it drifts.
  • Does distance matter? Run the same pair close together, then far apart.
  • Change one thing per run. If you change two, you will not know which one caused the difference.
